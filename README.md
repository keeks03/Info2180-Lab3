# INFO2180 Lab 3
This is Lab 3 for Akeelia Phillibert.

## Overview
This lab involves creating a simple Tic-Tac-Toe game using HTML, CSS, and JavaScript.

The HTML and CSS were provided as starter files, and all game logic and interactivity were implemented using JavaScript.

## Files
- index.html – main structure of the page  
- tic-tac-toe.css – styling for the layout and game board  
- tic-tac-toe.js – JavaScript logic for game behavior  
- tic-tac-toe-bg.png – background image  
- README.md – project description file
